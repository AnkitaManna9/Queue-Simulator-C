About the project

This project demonstrates how a linear Queue Abstract Data Type (ADT) models real-world waiting lines. The simulator follows the First-In, First-Out (FIFO) principle: the first customer or print job to enter the queue is the first one removed for service.

Core queue operations

  • enqueue() – add an entity at the rear.
  • dequeue() – remove the entity at the front.
  • peek() – inspect the front entity.
  • size() – return the number waiting.

Simulation objectives

  • Generate probabilistic arrivals.
  • Manage a single FIFO service queue.
  • Track arrival, start and completion ticks.
  • Calculate average waiting time, maximum queue length and server utilization.

Model note: This is a browser-based educational implementation of the algorithm described in the project report. It uses JavaScript so it can run on static hosting such as GitHub Pages.
